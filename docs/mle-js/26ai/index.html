    All MLE modules (mle-js)

    All-In-One bundle for JavaScript APIs in Oracle Database

    Oracle Database allows executing user-provided JavaScript code since version 21c by using the Multilingual Engine (MLE). This documentation describes mle-js which contains all relevant declarations of predefined JavaScript modules that ship with the database plus the declarations of all global symbols.

    MLE Modules

    Oracle Database ships with some predefined JavaScript modules:

    • MLE SQL Driver: mle-js-oracledb
    • MLE Bindings: mle-js-bindings
    • MLE PL/SQL Types mle-js-plsqltypes
    • MLE Fetch API polyfill mle-js-fetch
    • MLE Encoding API: mle-js-encodings
    • MLE Base64 Encoding: mle-encode-base64
    • MLE Foreign Function Interface (FFI): mle-js-plsql-ffi
    • MLE Web APIs: mle-js-webapi

    Global Symbols

    The following symbols exist in each JavaScript context in Oracle Database:

    • console
    • Polyglot
    • oracledb: shorthand for getting direct access to mle-js-oracledb without importing it
    • session: shorthand for the mle-js-oracledb default connection; is used to issue SQL statements directly
    • soda: shorthand for the mle-js-oracledb SODA Database object which can be used to create SODA collections

    • plsffi.resolvePackage (since Oracle 23.7)
